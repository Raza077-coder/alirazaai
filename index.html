Features

Everything you need to go hands-free

Every component is real and functional — no mockups, no fake success messages.

📱

iPhone Camera

Use your iPhone as the main camera — clearer than a laptop webcam. Connects over Wi-Fi or USB via IP Webcam / DroidCam / USB UVC. Auto-detect, low latency, OpenCV-compatible.

✋

Hand Tracking

Real-time 21-landmark hand tracking. Detects left/right hand, fingers, palm, wrist, position, movement, direction and speed. Optional landmark overlay.

🖱️

Gesture Control

Move index finger → move cursor. Pinch → left click. Pinch+hold → drag. Two-finger → right click. Open palm → stop. Swipes → scroll & navigation. Fully configurable.

🎙️

Voice Control

English + Roman Urdu. "Chrome kholo", "Volume barhao", "Computer lock karo", "Screenshot lo", "Search YouTube for…", "Type…" and more. Executed safely.

🎮

Gaming Mode

Fighting-game ready (e.g. Tekken). Editable Gesture → Keyboard mapping: Right Punch → J, Left Punch → K, Block → hold L, hand direction → move. No hard-coded controls.

🥊

Punch Detection

A proper temporal detector: rapid forward movement + fist shape change + speed over a configurable threshold = PUNCH. Detects direction, speed, hand, start & impact. Adjustable sensitivity.

🧠

Voice + Gesture Combo

Point at a window and say "Isay open karo". Use a hand gesture for the mouse and say "Click karo". Both inputs combine contextually in real time.

🛡️

Safety First

ENABLE/DISABLE controller button. Emergency stop shortcut Ctrl+Alt+X. Dangerous actions (shutdown/restart) require voice confirmation.

⚙️

Full Settings

Camera source, resolution, FPS, sensitivities, voice language, microphone, keyboard/mouse mappings, gesture mappings, gaming mode. Saved locally in settings.json.

Installation

Get it running in minutes

This is a Windows desktop application — it runs locally on your PC, not in a browser.

1 Install Python 3.9+

Download from python.org and check "Add Python to PATH" during install.

2 Install dependencies

cd project
pip install -r requirements.txt

If PyAudio fails on Windows: pip install pipwin && pipwin install pyaudio

3 Connect your iPhone

Install IP Webcam or DroidCam on your iPhone, start the stream, and set the URL in Settings. USB UVC also supported.

4 Run it

python main.py
# or the dashboard:
python ui/dashboard.py

First-time calibration is guided in the app.

Note: This is a Windows desktop application (Python). It cannot run in a browser. The microphone and iPhone camera must be present on your local machine. All processing is local — nothing is uploaded.
Safety & Security

You stay in control, always

🛑 Emergency Stop

Press Ctrl+Alt+X at any time to instantly disable all automated control — mouse, keyboard, and PC commands.

🔘 Enable / Disable

A clear ENABLE/DISABLE CONTROLLER button. When disabled, nothing is automated.

⚠️ Confirmation Required

Shutdown and restart require voice confirmation. "Computer shutdown karo" → "Are you sure?" → "Yes" → execute.

🔒 Privacy

All processing is local. Camera and video data are never sent to external servers. No credentials are stored or exposed.
